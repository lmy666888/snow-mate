## [1.0.0] — 2026-11-23 · M1.0 UI Foundation Prototype

- Preserve the runnable Expo / React Native UI foundation with five tabs, 31 product routes and one component state gallery.
- Pink/plum design system and bundled Allura script wordmark following owner feedback.
- Fictional discovery, trip, pricing, motion, community and profile previews; ephemeral interactions only.
- Essential PostgreSQL schema with 11 RLS-protected tables and a server-controlled mutual-like RPC, not connected to mobile.
- Shared types, sensor protocol contract, architecture documentation, 19 browser review screenshots and reproducible checks.
- Limitations: no production backend, real AI coaching, live ticket prices, BLE, native iOS build or physical iPhone verification.
