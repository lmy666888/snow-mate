## 失败与修复

开发时曾有失败，均未作为成功计数：翻译处理导致标点空格丢失、按钮选中态语义、空字符串条件触发 View 警告；错误的筛选预期和测试运行相互争用服务器/输出。已修复并以串行完整运行确认。

首次 hosted CI 在干净 Linux 环境发现 Web-only touchAction 样式类型问题；删除非必要样式后触摸回归通过。增加设置可见性断言发现 Web Constants 没有动态 extra 元数据；改用从 VERSION/Git 生成的忽略 bundle JSON，并通过本地/CI 版本显示断言。旧失败/取消 run 保留，未重写历史或隐瞒。

## 不能据此宣称的状态

没有完整 Xcode、Simulator 或实体 iPhone 验证。原生图库/权限、文件持久化、VoiceOver、动态字号、键盘、modal/分享/动画与性能待设备确认；HEIC/AVIF 不在当前明确支持的 JPEG/PNG/WebP 范围内。

没有真实 Auth、服务端成人核验、照片云上传/EXIF 清理、安全图片服务、真实互赞/Realtime、AI 正确率、实时价格或 BLE 测量。当前为本机演示候选，不是生产发布。
