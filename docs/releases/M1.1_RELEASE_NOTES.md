# Snowmate M1.1 — 1.1.0 Demo Release Candidate

Owner 于 2026-11-23 明确通过功能演示阶段验收，见 [审批记录](M1.1_APPROVAL.md)。这是**演示候选版，不是生产版**。候选分支中的 1.1.0 版本准备完成不等于已合并或创建 v1.1.0 标签。

## 内容

中英动态切换与本机语言保留；独立的国家/城市/探索地区/距离/单位/币种；七步本地身份引导；最多六张本机照片、主图/排序/删除；个人中心与图库；40 位确定性虚构成人；真正作用于演示资料的筛选、已看/屏蔽排除、单向喜欢不配对、预设双向喜欢配对、本地聊天与持久化；来源明确的运动架构契约。

## 明确限制

没有 iPhone 原生/实体设备验证，没有真实认证、成人核验、后端/云存储/真实互赞/Realtime 集成。照片仍为本机保存，可能保留源元数据，支持 JPEG/PNG/WebP；不是生产图片安全方案。Trips/Prices/Coach/Community 仍有原型边界；没有实时报价、真实传感器数据或已验证 AI 教练准确率。

## 验证与发布条件

版本调整后重新执行类型、Lint、单元/UI、Web/iOS JS 导出、兼容检查及秘密扫描；结果见 `M1.1_RELEASE_STATUS.md`。iOS JS/Hermes 导出不等于 native build。

PR #1 必须满足既有独立审批与 CI 规则。只有实际合并到 main 并确认提交后，才能把注解标签 v1.1.0 指向该合并后的发布提交。没有有效独立审批时，不合并、不打标签、不部署，不创建 GitHub Release 对象。M1.2 仍受其 M1.1 已合并前置条件约束。
