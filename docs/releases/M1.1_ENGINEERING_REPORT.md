## 实现边界

- `i18n/` 使用 i18next/react-i18next 的显式 en/zh 资源。共享 AppText/Button/Field 等解析 phrase keys；动态姓名/用户输入原样保留。切换语言不更改地区、单位或币种。距离和金额由 Intl 格式化；旧票价固定为 USD，绝不按显示币种伪造汇率换算。
- `features/regions` 使用手选城市与城市中心距离。目录仅 9 个城市，非完整全球地区库。没有精确 GPS、街道地址或后台定位。
- `features/identity` 是本地身份引导。真实 Auth 计划在 M2.0，因此“账号预览”不能宣称已注册。账号预览至少一张本地照片且完成引导才可探索；所有模式均限制 18–100 岁本地自报年龄。真正成人验证和服务端准入尚未实现。
- 本机照片由图片选择器获取：原生保存到 App 的文档子目录；Web 保存到 IndexedDB 并在重载后重新建立 Blob URL。异步保存/读取失败可见。原生路径未实际设备验证。元数据可能保留，尚无 EXIF 清理或恶意文件深度扫描，不可以此推出生产图片安全。
- `demoRepository` 是查询边界；`logic.ts` 是纯社交状态转换；`stores/social.ts` 使用独立版本化存储键 `snowmate:m1.1:demo:v1`。已看、喜欢、匹配、屏蔽、聊天和身份/偏好保留本地，加载时校验结构，存储不可用会明确提示。
- 40 位雪友使用各自姓名缩写与配色占位，卡片通用山景为已授权库存图。没有把重复库存人像冒充 40 位真实人物。
- 配对只由预置的 `likesCurrentUser` 与本次 Like 组合产生；单向点赞不会出现配对，也无法通过直接打开 Match 页面冒充。Undo 仅最近一次滑动，开始发送聊天后不能撤销生成该聊天的配对，避免静默删消息。拉黑移除本地配对/聊天并排除资料。
- `sensor-protocol` 准备了 MotionSample/Provider/Session/Event/Features/CoachReport/CalibrationMetadata/DataOrigin，带 SI 单位、版本、来源、校准和质量元数据。没有实现 M1.2 的 100 Hz 模拟器、转弯检测或 AI 教练。

## 工程治理

GitHub Flow 与 Conventional Commits；VERSION 是应用版本来源，当前 `1.1.0-dev`，设置展示 M1.1 Development 与可用 Git SHA。构建时从 Git 派生 SHA，经 build-metadata.mjs 生成忽略的 bundle JSON，不依赖 Web 上缺失的 Constants extra，不手写冒充；截图显示的是其构建时 SHA，提交之后重新启动/导出才更新。

main 的真实保护已通过 GitHub API 确认：verify/database 检查、严格最新状态、一次审批、管理员也执行、解决会话、禁止强推/删除。PR 模板、CI 与开发/分支/测试/编码/DoD/发布规范已添加。Owner 也是 PR 作者时，GitHub 不允许自批，可能需要另一位授权 reviewer；不会自动弱化保护。

## 验证与修复记录

完整命令和最终统计写入 `docs/testing/M1.1_VERIFICATION.md`。有意义的本地测试覆盖：40 人种子、全部过滤条件、单向/双向点赞、Undo/消息/拉黑一致性、成人/照片资格、MIME/魔数/体积、翻译键及插值一致性、地区/单位格式化、持久化字段恢复；浏览器测试覆盖所有 35 路由以及真实触摸、本机照片、语言/地区独立保留和原型回归。

开发中发现并修复：翻译归一化丢失标点旁空格、选项缺正确按钮选中语义、空字符串条件渲染导致 RN Web 的 View 文本警告。筛选测试最初错误地假定近距离下无符合条件的人，已改成验证实际波士顿匹配人物后再测试空结果。曾发生两个测试运行争用开发服务器/输出目录的基础设施失败，最终验证串行独立运行，不把这类失败误报为通过。干净 Linux CI 发现 Web 专用 touchAction 的类型兼容问题，已去掉并通过触摸回归；新增实际版本检查发现 Web Constants 缺少 extra build，已改成从 VERSION/Git 派生的 bundle 元数据。

浏览器测试与 bundle 导出不是 iPhone 验证。没有 Xcode/Simulator/可用实体设备；VoiceOver、最大字号、原生照片选择与权限、键盘、分享及原生动画/流畅性仍需验证。

## 安全复核

- 工作树及全部可达 Git 历史执行有限规则扫描，不打印秘密；没有 API key、service role、真实认证 token 或私钥。依赖/浏览器/数据库/构建/环境/缓存不入 Git。
- AsyncStorage/IndexedDB/本机文件不是加密凭据存储，不存密码、token 或真实云端授权。存储模式只用于演示；不可作为 M2.0 的认证实现。
- 本地年龄/照片/匹配检查不是服务端授权。M1.0 SQL 的 RLS/RPC 保留且未新部署。真实多用户场景必须使用服务端强制。
- 城市中心仅作距离估算，所有人物明确虚构。用户自己选择的照片仅在本机；截图使用仓库已有授权素材，不包含个人相册。
- 字节魔数、MIME 和 5 MB 上限是初步校验；源图可能带 EXIF，未来云上传必须去敏、权限隔离、服务端再次校验、恶意文件检测和删除/保留策略。
- 没有支付、实时票价、GPS、生产消息发送、真实运动测量、AI 准确率结论或生产部署。
