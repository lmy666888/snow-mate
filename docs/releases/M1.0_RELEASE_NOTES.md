# M1.0 — v1.0.0 UI Foundation Prototype

日期：2026-11-23。此版本是可复现工程基线，不是生产发布。Owner 明确授权将当前已完成原型保存和推送到指定 GitHub 仓库。

## 内容

五标签 Discover / Trips / Coach / Community / Profile；Prices 从 Trips 进入。31 个产品路由及 1 个组件/状态页，覆盖引导、人物详情/示例匹配/聊天、行程输入/固定结果/详情、虚构价格、合成运动图表、社区和个人中心。粉色底图、梅紫操作色、Allura 花体 Snowmate。库存照片与字体授权随仓库保存。

局部交互包括：拖拽与按钮滑卡、示例庆祝、临时聊天/评论输入、内存资料/收藏、行程活动编辑、暂停/断连预览、手动分享。不等同于完整 Demo Functional；重载会丢失临时状态。

工程包括 pnpm workspace、Expo SDK 58、React Native 0.88、Router、严格 TypeScript、Zustand、TanStack Query provider、共享类型和传感器协议契约。11 个基础 SQL 表启用 RLS，互赞 RPC 和 membership/block 权限已通过独立本地数据库测试，但 App 没有接入 Supabase。

## 验证命令与平台边界

基线复核执行 `pnpm install --frozen-lockfile`、`pnpm typecheck`、`pnpm lint`、`pnpm test`、`PLAYWRIGHT_BROWSERS_PATH="$PWD/.local/browsers" pnpm test:ui`、`pnpm build`、`pnpm --filter @snowmate/mobile exec expo export --platform ios --output-dir dist-ios` 和 `pnpm test:db`。结果记录在 `docs/releases/M1.0_BASELINE_VERIFICATION.md`。早期复核记录在 `docs/testing/DAY1_VERIFICATION.md`，作为历史材料保留。

浏览器截图在 `docs/design/review/day1/`，是 Web 移动视口截图。iOS JS/Hermes bundle 不代表原生编译、签名、安装或真机测试。
