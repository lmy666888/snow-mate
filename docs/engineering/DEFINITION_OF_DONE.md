# Definition of Done

A feature requires: satisfied acceptance criteria; meaningful relevant tests; typecheck/lint; no known critical regression; docs and actual screenshots updated; security/privacy reviewed; traceable focused Git commit; owner milestone review when required. A feature failing criteria stays incomplete even if attractive.

Report separately:
- UI Complete: representative layout/navigation and interaction states available.
- Demo Functional: advertised deterministic local behavior and persistence work under tests.
- Backend Integrated: real service boundary and authorization verified, not fixtures.
- Device Tested: named actual device/runtime checked; browser or JS export does not qualify.
- Production Ready: security, operational, reliability and release criteria independently met.

For M1.1, no merge, v1.1.0 final tag, GitHub Release or M1.2 without explicit owner approval. Draft PR and CI do not substitute for approval.
